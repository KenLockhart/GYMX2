# Homepage promotional image provenance

All images listed here were generated for the GymX2 homepage using the built-in image generation tool. The depicted people and scenes are synthetic promotional imagery; they are not members, coaches, testimonials, or account photos. No live profile or community media is loaded by the homepage.

The optimized WebP files under `public/homepage/` were created with Sharp 0.35.5 from the generated source images. The discipline atlas was divided into its uniform five-column, two-row cells without adding creative edits. Next Image provides responsive browser sizes; only the hero collage is preloaded.
